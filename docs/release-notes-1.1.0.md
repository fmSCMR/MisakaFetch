# MisakaFetch V1.1.0

## 新增与改进

- 主标题、副标题和主题按钮始终显示。
- “视频封面提取”入口支持展开和收起，保留输入与提取结果。
- 提取页卡片支持底色、边框颜色及透明度调整；设置页保持默认外观。
- 默认背景模糊改为 0，滑块为接近清晰的区间提供更多调节空间。
- 亮暗主题统一黑色背景遮罩，默认强度 35%。

## 修复

- Windows 限制为单窗口，重复启动唤回已有窗口。
- 修正界面动画开关说明及返回动画行为。
- Windows 各运行副本独立保存设置和背景。
- 收起提取区域时释放输入焦点，窗口缩放不丢失输入和结果。

## 下载与使用

- Windows：完整解压 `MisakaFetch-V1.1.0-Windows-x64.zip`，运行 `Windows/MisakaFetch.exe`，保留所有 DLL 和 `data`。
- Android：安装 `MisakaFetch-V1.1.0.apk`，沿用 V1.0.0 的签名和应用 ID。
- `SHA256SUMS.txt` 提供两个安装包的 SHA-256 校验值。

Windows 升级时保留自己的 `user_data`。从 V1.0.0 升级到新目录时，可能需要重新选择背景和偏好；旧设置文件不删除。
